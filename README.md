# EasyAuthenticator 简易TOTP验证工具
## 一、软件简介
EasyAuthenticator 是一款本地离线运行的Windows桌面TOTP二步验证工具，对标谷歌验证器，专门用于生成标准TOTP动态验证码，为各类平台账号提供2FA双重身份防护，密钥本地加密存储，不上传云端数据，保障密钥隐私安全。

## 二、核心功能
1. **实时动态验证码展示**
    按标准30秒周期刷新当前有效TOTP校验码，附带倒计时提示，清晰查看剩余有效时长；同时展示上一轮、下一轮备用验证码，切换窗口期也可兜底使用。
2. **全量密钥管理**
    内置密钥管理模块，支持批量添加、删除平台TOTP密钥，适配网站、开发平台、云服务等多场景2FA需求。
3. **校验码导出备份**
    支持导出密钥与校验信息，方便本地备份、迁移密钥数据，避免设备丢失导致密钥遗失。
4. **安全底层设计**
    密钥采用AES加密本地存储，杜绝明文泄露；内置软删除逻辑，误删密钥可追溯恢复。

## 三、核心优势
- ✅ 完全离线运行，无需联网即可生成验证码，无云端数据泄露风险
- ✅ 直观倒计时+前后轮验证码预览，适配登录窗口期衔接场景
- ✅ 轻量化WinForm桌面工具，启动快、占用资源低，适配Windows全主流版本
- ✅ 自主管控密钥数据，加密存储+备份导出双重保障账号凭证安全

## 四、适用场景
GitHub、云服务器、社交账号、支付平台、企业后台等所有支持TOTP协议的平台，替代在线验证工具，自主掌控2FA安全凭证。
